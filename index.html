3. Pénalités d’exécution

Indiquez le nombre d’occurrences de chaque faute. Les pénalités sont cumulatives.

4. Exigences de combinaison

L’impression générale s’ajoute aux exigences validées, même si aucune exigence n’est validée. La note de combinaison est plafonnée à 4.
